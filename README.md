## Built with

[Nuxt 4](https://nuxt.com) with static generation, [@nuxt/content](https://content.nuxt.com) for markdown-driven routing and Shiki highlighting, [Tailwind CSS](https://tailwindcss.com), deployed to [Cloudflare Pages](https://pages.cloudflare.com).

Lessons live in `content/<course>/day-NN.md`. Course metadata lives in `content/courses/<course>.yml`.

## Development

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm generate   # static build
pnpm preview    # serve the static build
pnpm lint
pnpm typecheck
```

## Adding a course

1. Create `content/courses/my-course.yml`:

   ```yaml
   order: 4
   title: "Course Title"
   description: "Short description."
   slug: my-course
   color: "#10B981"
   lessons: 10
   weeks:
     - number: 1
       name: "Week Name"
       subtitle: "Week subtitle"
       color: "#3B82F6"
   ```

2. Add `content/my-course/day-01.md` through `day-NN.md`, each with `title`, `day`, `week`, `weekName`, `description`, and `tag` frontmatter.

3. The landing page and routing pick it up automatically.

## Deployment

GitHub Actions deploys `.output/public` to Cloudflare Pages on every push to `main`. Requires the `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` secrets.

## Design

Dark and developer-first. Cyan `#00E5CC` and magenta `#FF006E` accents, Space Grotesk for headings, DM Sans for body, JetBrains Mono for code, Shiki `github-dark` code blocks with a copy button. Mobile-first, two-column on desktop.
